# Тапалка - PWA Игра

Мини игра тапалка доступная в браузере как Progressive Web App.

## Описание

Это инкрементальная игра (idle/tap game), где нужно:
- Тапать по экрану для заработка монет
- Повышать уровень (прогресс зависит от количества тапов)
- Покупать навыки для увеличения дохода
- Получать пассивный доход

## Особенности

- ✅ PWA - можно установить на устройство
- ✅ Адаптивный дизайн (соотношение 9:16)
- ✅ Без скролла, занимает всю высоту viewport
- ✅ Система уровней с прогресс-баром
- ✅ Пассивный заработок монет
- ✅ 4 навыка для улучшения
- ✅ Сохранение прогресса в localStorage
- ✅ Работает офлайн (после первой загрузки)

## Запуск

1. Откройте `index.html` в браузере
2. Или запустите локальный сервер:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (npx)
   npx http-server
   ```
3. Откройте `http://localhost:8000` в браузере

## Иконки для PWA

Для полноценной работы PWA нужно добавить иконки:
- `icon-192.png` (192x192 пикселей)
- `icon-512.png` (512x512 пикселей)

Можно создать простые иконки с помощью любого графического редактора или использовать онлайн генераторы иконок.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid)
- Vanilla JavaScript
- Service Worker (PWA)
- LocalStorage (сохранение прогресса)

## Игровая механика

- **Уровни**: Прогресс заполняется от количества тапов. При достижении нового уровня увеличивается доход за тап и пассивный доход.
- **Монеты**: Зарабатываются за тапы и пассивно (в зависимости от навыков).
- **Навыки**:
  1. Железные Небеса - увеличивает монеты за тап
  2. Фокус Героя - увеличивает пассивный доход
  3-4. Героическая Задержка - добавляет время к таймеру
